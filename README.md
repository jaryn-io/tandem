<h1 align="center">Tandem</h1>

<p align="center"><strong>Run long delegated work without babysitting it.</strong></p>

A single long chat drifts: context piles up, the brief blurs, and checking the result always lands back on you. Tandem moves work forward in bounded steps — production and review separate, decisions with you, everything on one inspectable record. What comes back is reviewed, not just finished.

This repository holds the official releases, the documentation and the verified examples of Tandem, the first product from [Jaryn](https://github.com/jaryn-io).

## Install

One `.deb` package — application, local agent and command-line interface — with a signed APT repository for updates. Ubuntu, native or under WSL2 on Windows. Installation instructions are published with the first public release.

## Read a real session first

Complete records of real sessions, every message: [jaryn-io/sessions](https://github.com/jaryn-io/sessions).

## Documentation

- User manual: installation, setup, daily use, update, reset. Published with the first public release.
- What Tandem does and does not promise: it governs the process and makes the proof inspectable; it does not promise that every result is correct without judgement.

## Your models, your choice

Tandem works with the CLI subscriptions you already pay for — Claude Code, Codex, Gemini CLI, Kimi and GLM — and connects directly to provider APIs when that serves you better. No model name lives in the core.
