1. Fictional Workshop Walkthrough (AeroPrecision Machining Lab)

AeroPrecision is a precision contract manufacturer producing mission-critical parts across 5 shared machine centers over a 5-day standard working week (Monday through Friday, 08:00 – 17:00, 45 operating hours total).

  • M1 — Haas UMC-750 (5-Axis Mill): Precision multi-surface contouring for aerospace parts. Has a planned spindle PM on Tuesday afternoon (13:00–17:00).
  • M2 — Haas VF-2SS (3-Axis Mill): High-speed milling for prismatic parts, bolt patterns, and pocketing.
  • M3 — Doosan Lynx 2100 (CNC Lathe): Precision cylindrical turning, threading, and boring.
  • M4 — Amada Ensis 3015 (Fiber Laser): Profile laser blanking and plate stock preparation.
  • M5 — Zeiss DuraMax (CMM Metrology): Quality assurance, surface roughness, and dimensional certification.

2. Scheduling Engine Principles & Constraints

  • Working Calendar & Shift Boundaries: The shop operates strictly Monday through Friday 08:00–17:00 (18 thirty-minute slots per day, 90 slots across the week). Work pauses overnight (17:00 to 08:00 next morning) and resumes automatically. When an operation spans across 17:00, the schedule displays a Cont. <Day> indicator badge, and non-working overnight time is not counted against duration.
  • Setup Time Treatment: Every operation explicitly specifies both Setup Hours and Run Hours. Setup occurs during the initial slots on the assigned machine before production run. Setup occupies machine capacity and is visually distinguished by diagonal cross-hatching and a wrench indicator.
  • Precedence Constraints: For every job, manufacturing operations must execute in strictly sequential order (e.g. Op 10 must complete before Op 20 can begin). If a user drags an operation earlier than its predecessor, a critical Precedence Violation conflict is flagged.
  • Machine Capacity Limits: Each machine is a single-spindle resource: at most one operation can occupy the machine at any time slot. Collisions trigger a Machine Overlap Conflict.
  • Planned Outages: Outages block machine capacity. Any operation scheduled during an outage generates an Outage Collision Conflict.
  • Unscheduled Work Handling: Work that cannot be placed within the available 45-hour weekly horizon remains clearly visible in the Unscheduled Work queue.

3. Reproducible Demonstration Scenarios

  • ⚡ Simulate Urgent Order: Injects an emergency aircraft part (JOB-901: A320 Flap Actuator Mount) due Wednesday noon. This creates direct capacity competition across Lathe M3, Mill M1, and CMM M5. Notice how it collides with M1's planned outage and competing jobs! Click Propose Schedule to see how high priority rearranges the board.
  • 🔧 Simulate Extended Outage: Extends the Haas UMC-750 maintenance window through Wednesday noon. Watch the conflict diagnosis panel immediately flag colliding operations with suggested remedies.
  • ⟲ Restore Demo: One-click reset restores the workshop back to its baseline schedule. Full multi-level Undo (Ctrl+Z) and Redo (Ctrl+Y) are supported for all actions!

4. Accessibility & Non-Color Indicators

ShiftBoard does not rely solely on color to communicate status: distinct icons (⚡ Urgent, ▲ High, ● Normal, ▼ Low), explicit text chips ([ON TIME], [LATE +3h], [⚠ CONFLICT]), cross-hatched setup stripes, and hazard hazard stripes for outages guarantee immediate readability across all visual capabilities.

5. Local Startup & Licensing

ShiftBoard is 100% self-contained. It requires zero external web services, CDNs, accounts, or background databases. Simply open index.html in any modern browser, or launch via python3 -m http.server 8080.
